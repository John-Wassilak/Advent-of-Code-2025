# Advent of Code 2025
Solutions to the [AoC 25](https://adventofcode.com/2025) puzzles.

Not doing anything crazy like last year

## Running
* To build executables just run `make`
* `make check` runs valgrind to check for mem leaks
* Each exe pulls the input for that day using curl, it assumes you have an env variable called `AOC_COOKIE`. Grab it by pulling input via the browser and copying the cookie in the request.
